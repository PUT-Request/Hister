# Hister (Fork)

A fork of [asciimoo/hister](https://github.com/asciimoo/hister) with **hybrid encryption** and **password protection**.

Hister is a private search engine for the pages you visit and the files you keep. It indexes their full contents so you can find information again from the web interface, terminal, or an AI assistant connected through MCP.

## Setup

For installation and setup instructions, please follow the [original Hister documentation](https://github.com/asciimoo/hister).

## Changes from Upstream

- Hybrid encryption for indexed data
- Password-based authentication
